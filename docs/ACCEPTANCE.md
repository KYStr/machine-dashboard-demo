# 驗收清單

本清單供人工逐項操作；程式存在不代表原生 App 或正式環境已完成。

| 項目 | 操作 | 預期結果 |
|---|---|---|
| 預設狀態 | 開啟看板 | A 運轉、B 異常、C 待機；三種統計與總數一致 |
| 即時更新 | 等待更新或設定每秒 | 溫度、RPM、產出速率與圖表更新；待機轉速及速率為零 |
| 高溫 | 展示設定 → A → 模擬高溫 | A 變紅，通知及警示紀錄出現 |
| 去重 | 再按相同機台高溫 | 同一異常不重複新增事件 |
| 恢復 | A → 恢復正常 | 回到運轉，舊事件保留且標示已解除 |
| 歷史 | 最近一小時 ↔ 最近一天 | 時間範圍與曲線改變 |
| 指標 | 溫度 ↔ RPM ↔ 產出速率 | 標題、數值、刻度與單位同步切換 |
| 圖表提示 | 指標移動或聚焦後按方向鍵 | 顯示相應時間與數值 |
| 詳情 | 點機台卡片 | 三種完整圖表；Esc 可關閉 |
| 搜尋 | 搜尋 MC-003 或篩選待機 | 正確縮小清單；無結果可清除 |
| 12 台 | 主畫面點 12 台或設定選 12 台 | 不必按套用，立即出現 12 張卡片 |
| 30／60 台 | 切台數，按顯示全部 | 先顯示 12 台及剩餘數，展開為 30／60 張實際卡片 |
| 舊篩選 | 搜尋並篩選後切台數 | 搜尋及狀態條件清空 |
| 手機 | 320、360、375、390、430px | 無整頁水平溢出，卡片／列表及底部導覽可使用 |
| 平板桌面 | 768、1024、1440px | 版面合理、字與圖表不互蓋 |
| CSV | 歷史匯出 | 包含台北時間、機台、單位、模擬來源 |
| 暫停 | 控制台勾選 | 數字停止並標示暫停 |
| Node 同步 | 兩分頁操作 | 另一分頁經 SSE 收到狀態，靜態模式不適用 |
| 中斷 | 停止 Node 服務 | 保留最後值並標示中斷 |
| PWA | HTTPS／localhost | 檢查快取、離線及支援瀏覽器的安裝入口 |
| SEO | 使用真實 SITE_URL 建置 | canonical、OG、sitemap 指向正式站點 |
| Git | 查看提交紀錄 | 功能分階段提交，不重寫既有遠端紀錄 |

## 需另行驗證

實體 iPhone／Android 安裝、WebView 與安全區、原生 APK／IPA 簽章、商店上架、正式域名 HTTPS、搜尋引擎收錄。GitHub 原始碼提交與網站正式部署是兩件事。

## 重新開始

Node 模式重啟服務；單檔／靜態模式重新載入。主題與卡片／列表偏好可能保留在目前瀏覽器。這是記憶體示範，不會刪除真實工廠資料。
